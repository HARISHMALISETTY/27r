CSS POSITIONS


WHAT?

POSITIONS ARE THE ONE OF THE MAIN PROPERTY/FEATURE IN CSS TO CONTROL THE POSITION OF ELEMENT IN THE WEBPAGE.



WHY?

WHENEVER WE WANT TO CHANGE THE POSITION OF AN ELEMENT WITHOUT DISTURBING THE EXISTING CONTENT, WE CAN USE POSITIONS.



HOW?

POSITIONS ARE IMPLEMENTED WITH FOLLOWING PROPERTIES

1.STATIC---DEFAULT POSITION OF ANY ELEMENT
2.ABSOLUTE-- element's position can be control with its viewport/ancestor referrence.
3.RELATIVE-- element's position can be control with its normal position.
4.STICKY
5.FIXED--- It will fixes the position of element at particular place.

AFTER APPLYING SPECIFIC POSITION PROPERTY TO AN ELEMENT, WE CAN CONTROL THEIR POSITION WITH PROPERTIES--TOP,LEFT,RIGHT,BOTTOM.

HOWEVER THOSE PROPERTIES WON'T APPLY/WORKS WITHOUT GIVING POSITION PROPERTY.


WHENEVER WE USE POSITIONS FOR AN ELEMENTS, THEY MAY GET OVERLAP. SO IN SUCH CASES WE CAN USE Z-INDEX PROPERTY TO DISPLAY THE ELEMENTS ON PRIORITY BASED.
